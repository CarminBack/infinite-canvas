# 待测试

- Token 多分组一键登录与模型目录：登录后自动创建或复用 `Image`、`Video`、`ChatGPT` 三个分组令牌，浏览器不接触真实密钥；生图动态显示 Token `Image` 分组的全部模型，并同步系统设置中的 1K/2K/4K 价格；视频显示 `Video` 分组全部模型及按秒/按条价格，视频模型选择项与已选模型下方同步显示模型广场的描述，文本使用 `ChatGPT` 分组，音频默认 `gpt-4o-audio-preview`。账号无权访问 `ChatGPT` 分组时不再阻断图片、视频模型和价格同步。需验证首次重新登录、默认模型、价格与视频模型描述展示、无 ChatGPT 权限账号刷新后的 Seedance 价格、刷新不再重复请求或触发 429，以及各能力请求使用正确分组。
- 固定 AI 代理剩余能力：模型列表和 `/v1/images/generations` 已完成生产验证；针对 Image2 高分辨率生成可能超过 Cloudflare 等待上限的情况，生图代理会持续发送 JSON 空白心跳，避免 Token 已完成但 Canvas 因连接被关闭而显示失败；视频任务已修复长耗时任务过早超时、New API `done` 成功状态和直链结果兼容、Seedance 经 Token/New API 错用原生任务路径的问题。Seedance 渠道 47-50 会按模型别名限制生成模式、分辨率、比例、4/5-15 秒时长和 9/4 图、3 视频、3/1 音频数量，并在创建任务前校验文生、图生和首尾帧的素材要求；仍需在不扣费测试模型或供应商测试环境验证各渠道创建载荷、视频任务自动恢复和结果播放/下载。
- 配置迁移剩余场景：配置页已不再显示 Base URL、API Key、渠道或调用格式；仍需验证旧浏览器配置和旧 URL 参数中的密钥清理。
- 登录生命周期剩余场景：未登录跳转、已登录访问、退出登录、跨站来源校验和容器重启持久性已验证；仍需验证 OAuth 超时/篡改、停用自动令牌和会话自然过期。
- 余额与充值入口：Canvas 右上角余额通过服务端使用 Image 分组令牌读取 Token 当前账号余额，不向浏览器暴露 API Key；点击余额菜单可打开 Token `/wallet` 钱包页面，需验证余额显示、刷新后余额更新、手机端布局和充值跳转。
